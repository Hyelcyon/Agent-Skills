# Research & Continuous Learning Skills

This directory provides specialized research, architectural spike, and continuous knowledge learning skills for Google Antigravity.

## Available Skills

| Skill | Description | Primary Use Case |
| :--- | :--- | :--- |
| **[light-research](./light-research/SKILL.md)** | Multi-hop web search, API signature extraction, falsification probing, and empirical verification. | Precision multi-query search, API contracts, breaking-change falsification, compiler error resolution, and library triage. |
| **[deep-research](./deep-research/SKILL.md)** | Multi-vector architectural spikes, gap-detection loops, Pugh trade-off matrices, and ADR formulation. | Evaluating major frameworks, database migrations, security threat models, and architectural pivots. |
| **[knowledge-learning](./knowledge-learning/SKILL.md)** | Systematic knowledge distillation, user feedback capture (/learn), and workspace memory persistence. | Capturing non-standard build flags, debugging post-mortems, monorepo quirks. |
