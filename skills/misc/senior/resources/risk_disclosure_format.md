# Risk Disclosure & Verification Format

When presenting changes in Senior mode, conclude with a concise risk and verification summary:

```markdown
### Verification & Risk Summary
- **Verification Evidence**: `[Executed Command]`: `[Exit Code & Output Summary]`
- **Excluded Scope**: `[Components or edge paths deliberately untouched to preserve minimal diff]`
- **Operational Risks**: `[Remaining risks or environmental dependencies for user awareness]`
```
