# Assembly Language Engineering Skills

This directory categorizes senior-grade Antigravity skills for low-level assembly language development across modern architectures.

## Supported Architectures

- [`x86-64`](./x86-64/SKILL.md): Modern 64-bit x86 architecture (AMD64 / Intel 64), NASM and GAS assembler tooling, System V AMD64 and Microsoft x64 calling conventions, AVX2 / AVX-512 SIMD vectorization, inline assembly, and stack alignment invariants.
- [`arm64`](./arm64/SKILL.md): 64-bit ARM architecture (AArch64 / ARMv8 / ARMv9), Apple Silicon and Linux platforms, AAPCS64 calling conventions, NEON SIMD vectorization, weakly ordered memory barriers, and link register / frame pointer chaining.
